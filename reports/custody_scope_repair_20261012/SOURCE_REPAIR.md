# Receipt decoding and fabrication evidence repairs

October 12 UTC / October 11 local, 2026. Source repair and receipt regressions; not a performance or historical position-restoration result.

The two first freezing receipts in [REPORT_AUDIT.md](REPORT_AUDIT.md) exposed unsupported Pump layouts and overbroad custody attribution. The decoder now recognizes the witnessed BuyV3 discriminator and quantity/maximum-cost limits, preserves the ExactQuoteInV2 partial-fill boolean, and does not attribute harmless nontrade Pump accumulator/event invocations to every mint. Receipt balance/custody coverage is checked for the traded mint. Real unsupported token mutations still quarantine their affected mints.

The actual offending receipts are frozen in `tests/fixtures/custody_current_4oyj_buy_v3.json` and `tests/fixtures/custody_current_71tj_exact_v2.json`. Their regression checks bind instruction mint/quantity, integer reserve spend and custody scope. The ExactQuoteInV2 witness reproduces reserve/custody parity without a paper intervention. An explicit partial-fill=true completion branch stays unresolved when its changed execution cannot be modeled; the regression preserves all inventory and proves that false/default clipping instead atomically reverts. These checks do not establish arbitrary outer-router conditional execution or restore previously quarantined positions.

The new [7soS8b admission audit](../fake_7soS8b_20261012/REPORT.md) found a paper S5 admission on Watch with incomplete evidence. The strict repeated-relay/funding conjunction was not established. Sampled transfers to the authenticated Pump curve PDA are sells, not wallet relays. The rule remains a narrow family detector, with unestablished coverage across user examples.

The recipe collector previously compared signature block timestamps with a stale scan-start clock. It now compares each signature query against its own response availability time. A regression accepts transactions produced during the scan and still rejects timestamps after response availability. Successful queries persist address, response availability, row count and reported timestamp range; excluded-future warnings include both reported time and exact cutoff. Old serialized scans remain readable. Existing request budgets, spacing and future-data exclusions are preserved. Historical 7soS8b query cutoffs were not saved, so this repair does not prove that those excluded signatures contained qualifying relays.

Full-suite verification exposed holder tests that mutated a shared environment variable or expected legacy funding requests with the new zero-probe default. Those tests now pass their funding limit directly to a private collector helper; production still uses the configured capped limit. This removes the parallel test race and mismatched mock-server request waits.

Validation results and final source/binary hashes are recorded separately in `VALIDATION.json`. Neither source compilation nor receipt tests activate the external shadow host. Existing quarantined inventory remains held: historical continuation/backfill is still necessary before those positions can regain executable marks. No runtime checkpoint, cash balance or position inventory was reset, and no exit was fabricated. Strategy definitions and Watch admission policy were unchanged.
